# Product Vision

Mosaic is a data-first design system for building glanceable, touch-first interfaces.

It begins as a Flutter design system and CLI, grows into a launcher and core app ecosystem, and can later support Linux shells, AOSP integrations, and experimental OS targets such as Fuchsia.

## Core Belief

Most modern mobile apps hide useful state behind too many pages. Mosaic reverses that.

```text
Apps should expose useful state first.
Navigation should be shallow.
Actions should be contextual.
Surfaces should be structured, not decorative.
```

## What Mosaic Is

- A design language
- A Flutter component library
- A stateful tile system
- A CLI for scaffolding and metronizing Flutter apps
- A launcher reference implementation
- A core app design framework
- A platform bridge strategy

## What Mosaic Is Not

- Not a Windows Phone clone
- Not a Material theme
- Not a launcher-only project
- Not random Flutter staggered grid UI
- Not a skin applied after app journeys are already broken

## Long-Term Direction

```text
Mosaic Design System
  ↓
Mosaic Flutter SDK
  ↓
Mosaic CLI
  ↓
Mosaic Launcher
  ↓
Mosaic Core Apps
  ↓
Native Bridges
  ↓
Linux Shell / AOSP / Fuchsia experiments
```
